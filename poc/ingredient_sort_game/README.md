# 식재료 손 제스처 분류 게임 POC

사용자가 카메라 앞에서 식재료 카드를 손으로 잡아 `못 먹어요`, `선호하지 않아요`, `좋아해요` 칸에 옮기는 독립 실행형 웹 POC입니다.

## 구성

- 3라운드, 총 23개 식재료 카드
- 화면에는 최대 4개 카드만 노출하고, 분류하면 다음 카드가 채워짐
- MediaPipe Gesture Recognizer의 `Open_Palm`, `Closed_Fist` 사용
- 손바닥 중심이 카드에 들어간 상태에서 주먹을 약 0.22초 유지하면 잡기
- 분류 칸에서 손바닥을 약 0.26초 펴면 놓기
- 마우스 드래그와 키보드 선택 대체 조작
- 결과 JSON 복사
- 서버·DB·기존 추천 엔진과 연결하지 않는 POC

## 실행

카메라는 `localhost` 또는 HTTPS에서만 사용할 수 있으므로 파일을 직접 열지 말고 저장소 루트에서 정적 서버를 실행합니다.

```powershell
python -B -m http.server 8765 --directory poc/ingredient_sort_game
```

브라우저에서 <http://127.0.0.1:8765>를 엽니다. MediaPipe 모듈과 모델을 CDN에서 받으므로 첫 실행에는 인터넷 연결이 필요합니다.

## 현재 한계

- 손 제스처 임계값은 실제 사용자 테스트 전의 POC 값입니다.
- 조명, 카메라 화각, 사용자의 손 크기에 따라 인식 감도가 달라질 수 있습니다.
- 결과의 `못 먹어요`는 바로 알레르기나 절대 불선호로 저장하면 안 됩니다. 다음 단계에서 이유와 세부 재료를 확인해야 합니다.
- 이 버전은 결과를 브라우저 메모리에만 두며 서버로 전송하지 않습니다.
