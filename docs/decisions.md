# 결정사항

> 구축을 시작하기 전에 사람이 정하는 항목입니다. 각 항목의 "결정"을 채우세요.
> 기본값을 그대로 쓰려면 "결정"에 `기본값`이라고만 적으면 됩니다.
> 에이전트는 "미정"인 항목이 작업에 영향을 주면 진행하지 않고 질문합니다.

## D1. 서비스 대상

- 기본값: 개인용 프로토타입(본인과 가족만 사용). 로그인 없이 사용자 프로필을 여러 개 만들어 전환하는 방식.
- 외부 공개라면: 면책 문구, 개인정보 처리 방침(알레르기는 건강정보), 로그인이 추가로 필요하다.
- 결정: 기본값

## D2. 선택 재료에 알레르기 성분이 있을 때

- 기본값: 레시피를 제외한다(안전 우선).
- 대안: "이 재료는 빼고 조리하세요" 안내와 함께 추천한다. 이 경우 CLAUDE.md 안전 규칙도 함께 바꿔야 한다.
- 결정: 기본값

## D3. 레시피 출처와 초기 수량

- 기본값: 에이전트가 일반적인 가정식 레시피를 직접 작성한 초안 50개(한식 위주, 일식·양식·중식 일부) + 사람 검수.
- 대안: 공공데이터(예: 식품안전나라 조리식품 레시피 DB) 활용. 이용 조건 확인 후 사용.
- 외부 블로그·사이트 레시피 본문은 복제하지 않는다.
- 결정: 기본값

## D4. 알레르기 그룹 기준

- 기본값: 국내 식품 알레르기 유발물질 표시 대상 목록을 기본 그룹으로 하고, 사용자가 이해하기 쉬운 묶음 그룹(견과류, 갑각류, 해산물, 생선 등)을 추가한다.
- 표시 대상 목록은 에이전트가 기억에 의존하지 않고, 사람이 최신 목록을 확인해 `knowledge/allergens.yaml`에 확정한다.
- 결정: 기본값. 목록은 아래로 확정(2026-10-03, 사람 확정)
  - 기본 그룹(법정 표시 대상 19개, `official: true`, 근거: 식품 등의 표시·광고에 관한 법률 시행규칙 별표 2): 알류(가금류), 우유, 메밀, 땅콩, 대두, 밀, 고등어, 게, 새우, 돼지고기, 복숭아, 토마토, 아황산류, 호두, 닭고기, 쇠고기, 오징어, 조개류(굴·전복·홍합 포함), 잣
  - 추가 그룹(비공식, `official: false`, `source: custom`): 기타 생선(고등어 외 생선), 참깨
  - 묶음 그룹: 갑각류(새우·게), 견과류(땅콩·호두·잣), 생선 전체(고등어·기타 생선), 해산물 전체(갑각류·오징어·조개류·생선 전체)
  - 반영 파일: `knowledge/allergens.yaml`

## D5. 화면(프론트) 방식

- 기본값: Streamlit. MVP 검증용으로 충분하다.
- 대안: 처음부터 React(Next.js). 구현 시간이 크게 늘어난다.
- 결정: 기본값
