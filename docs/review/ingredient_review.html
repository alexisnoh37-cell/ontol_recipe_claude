draft 재료 검수

미매칭 보강(um-2)으로 추가한 재료와 이전부터 검수 대기 중인 재료입니다. Claude가 미리 골라 두었으니 다르게 판단하는 재료만 바꾸세요. 다 끝나면 결과 내보내기로 받은 파일 경로를 Claude에게 알려 주면 knowledge에 반영합니다. 입력 내용은 이 브라우저에 자동 저장됩니다.

O 검수 완료(reviewed)로 바꿈(메모가 있으면 고친 뒤) · X 이 재료를 지움(그 표기는 다시 미매칭이 되어 알레르기 사용자에게 제외) · 보류 draft 그대로 둠. 알레르기 칸의 '(가능)'은 포함 가능이며 판정에서는 포함으로 간주합니다.
